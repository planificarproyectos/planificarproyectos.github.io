# CoordinaBIM

Coordinación BIM en el navegador: visor IFC federado, detección de interferencias (duras y de holgura, con estados, Excel y reporte con imágenes), TimeLiner 4D y cantidades de obra con precios.

Publicada en https://www.planificarproyectos.com/coordinabim/

Solo para cuentas de Planificar Proyectos SAS (empresariales o mixtas) en Planificar Proyectos Apps; el administrador puede quitar el acceso por persona en el panel. Los modelos IFC se procesan en el computador y nunca se suben a internet; los proyectos se guardan como archivo `.coordinabim.json`. Se puede instalar como app (Chrome/Edge: icono de instalar en la barra de direcciones; celular: "Agregar a pantalla de inicio").

El código fuente está en el repositorio privado `planificarproyectos/CoordinaBIM`; esta carpeta se genera con `npm run build` (`dist/sitio/coordinabim/`).
