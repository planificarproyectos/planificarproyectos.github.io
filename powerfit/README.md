# PowerFit

App web para entrenar en casa con mancuernas y tapete.

- Elige zonas del cuerpo y genera una rutina, usa una recomendada o arma la tuya.
- 27 ejercicios con figura animada e indicaciones.
- Botón para chulear cada repetición, temporizador y descansos automáticos.
- Progreso por semana, mes, semestre y año.

Publicada en https://www.planificarproyectos.com/powerfit/

Cuentas con correo y contraseña (Firebase Auth, mismo proyecto que Mindfocus). Datos en Firestore: `users/{uid}/powerfit` (usa las mismas reglas e invitaciones de Mindfocus).
Se puede instalar en el celular con "Agregar a pantalla de inicio".
